# F1 发车线镜像

发布工作流从原站拉取页面、资源和公开数据，再接入比赛实况、新闻和视频更新。实况源码在 `live/`，构建脚本在 `scripts/`。

## 本地预览

需要 Python 3.10+ 和 Node.js 22+。在仓库根目录运行：

```sh
python scripts/build-mirror.py
node scripts/build-live.mjs
python -m http.server 4175 --bind 127.0.0.1 --directory public
```

打开 [比赛实况](http://127.0.0.1:4175/#/live)。重新构建时先运行镜像脚本，刷新原站文件后再接入实况页。

## 实况数据

- TELOS 在浏览器里更新计时、分段、估算车位和赛会提示。计时、赛道地图、电台、赛会消息、FIA 公告和新闻显示在同一个大屏。Formuradar 和 Paddock Live 的入口可在底部展开。
- 实况页自动跟随当前场次，休赛时保留最近场次的赛后快照。完整赛果和其他场次在「比赛周末」查看。最近场次的快照未发布时，页面保留该场次标题并显示同步状态。
- 新闻、FIA 公告及 OpenF1 赛后计时、电台与赛会消息以静态 JSON 随网站发布。GitHub Actions 每小时调度一次。OpenF1 暂停匿名访问时，使用镜像已有赛程和上次成功缓存的赛后数据。
- GitHub Pages 部署由 `main` 的发布流程负责。实况页使用相对路径，支持仓库子路径下访问。

## 新闻和视频

- 新闻构建补全近期报道的官方链接和可读摘要。重点报道可在 `content/news-notes.json` 补充双语要点。译文未就绪时显示原文，中文页面打开期间每五分钟检查新闻文件。
- 视频使用 F1 世界锦标赛官号。哔哩哔哩沿用原站官号档案，新进片源按哔哩哔哩账号 ID 验证。抖音档案 `content/douyin-2026.json` 收录 2026 年能公开核验的官方视频，通过月份或片源筛选。档案随构建发布，缺少公开索引时，视频页提供官方账号入口。
