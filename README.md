# F1 发车线镜像

发布工作流从原站拉取页面、资源和公开数据，再接入比赛实况、新闻和视频更新。实况源码在 `live/`，构建脚本在 `scripts/`。

## 本地预览

需要 Python 3.10+、Node.js 22+ 和 Poppler 的 `pdftotext`。在仓库根目录运行：

```sh
python scripts/build-mirror.py
node scripts/build-live.mjs
python -m http.server 4175 --bind 127.0.0.1 --directory public
```

打开 [比赛实况](http://127.0.0.1:4175/#/live)。重新构建时先运行镜像脚本，刷新原站文件后再接入实况页。

## 实况数据

- 实况大屏参考 Paddock Live 的计时榜、赛道及车手详情、赛况流布局。TELOS 公开组件在赛中更新计时、旗况、领先车手和赛会提示。Formuradar 和 Paddock Live 可从底部进入。
- 实况页自动跟随当前场次。休赛时保留顶部导航，赛道照片预加载后淡入淡出，叠加下一站倒计时。首页在下一站首个场次开始时更换官方赛事精选照片。场次进行时自动切换至实况，页面底部可按场次比较两位车手的圈速、分段、进站和轮胎策略。完整赛果在「比赛周末」查看。
- 赛后分段、小段、轮胎、进站、天气、赛会消息和已发布电台使用 OpenF1。FIA 公告和赛后快照由 GitHub Actions 每小时刷新。OpenF1 暂停匿名访问时使用镜像赛程和已缓存的赛后数据。
- 比赛实况的赛道图统一使用 F1 官网高清官方图，点击可放大到 400%，支持拖动、滚动和恢复适应窗口。实况页、地图与计时段卡片沿用全站的背景色。
- 已公开的车队电台在构建时用多语言 Whisper 识别原语并转写，中文模式优先显示中文译文。GitHub Actions 安装转写依赖，缓存模型和已处理录音。本地可通过 `F1_RADIO_PYTHON` 指定安装了 `faster-whisper` 的 Python。未发布音频和未完成转写的条目显示相应状态。
- GitHub Pages 部署由 `main` 的发布流程负责。实况页使用相对路径，支持仓库子路径下访问。

## 新闻和视频

- 每次构建按赛季成绩自动生成中英文站内赛报，涵盖练习赛、冲刺排位赛、冲刺赛、排位赛和正赛，附可用的场次成绩。赛季资料还用于撰写车队复盘、积分形势、排位晋级线及车手和车队阶段分析。赛前自动生成下一站前瞻。新闻列表按月份和正文关键词检索。每次构建也检查 FIA 的当前和最近两站公开裁决，保留已核实的赛季档案，并将核实到的处罚结果、场次和证据整理成中英文报道。站内还刊登根据倍耐力、FIA 和车队公开信息独立写成的双语报道。
- 视频来源仅为哔哩哔哩及抖音官号。两个来源每三小时检查一次。哔哩哔哩从公开搜索检查最新投稿，按官号 UID 296086460 核验并按 BV 号去重。公开列表暂不可用时保留此前已核验的视频，并在下一次构建时重试。

## 规则查询

构建时从 FIA 现行规则目录核对 A–F 六卷，按 PDF 中每一页的词语建立倒排所需的检索数据。搜索结果定位到 FIA 原文页，站内阅读器可打开本地同语种 PDF 并跳到对应页。站内规则说明和界面随中英文模式切换。支持浏览器内置翻译的设备可对本地 PDF 逐页翻译文字，文件不上传，图表仍以原 PDF 为准。索引以 FIA 官方英文原文为准。
